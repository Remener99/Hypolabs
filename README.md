# Лемма

Агентная система роста для селлеров маркетплейсов и агентств. Ядро продукта — **знание о категории**: бенчмарки (где проходят нормы), паттерны лидеров (по каким признакам живёт топ) и события площадок. Всё остальное вытекает одной цепочкой:

**бенчмарк → гипотеза → тест → интерпретация → откат или масштабирование волнами**

Это один связанный объект, который проходит через разделы, а не пять независимых списков.

## Запуск

```bash
npm install
npm run build
npm start          # http://localhost:3000 — приложение и API на одном порту
```

При первом запуске база автоматически засевается демо-данными.

**Демо-вход:** `demo@lemma.ru` / `lemma2026` (кнопка «Войти в демо» на экране входа).

Режим разработки (API :3000 + Vite :5173 с прокси):

```bash
npm run dev
```

Полезные команды:

```bash
npm run seed       # пересоздать демо-данные
npm run test:ui    # смоук + интерактивные тесты собранного приложения (jsdom против живого API)
```

## Демо-данные

Кабинет мебельного продавца «Мебельград» с тремя категориями и заметно разными профилями паттернов:

- **Офисные кресла (WB)** — выигрывает контент: видео у 82% лидеров, 8+ изображений, съёмка в интерьере.
- **Стеллажи и полки (Ozon)** — выигрывает логистика: FBO-экспресс ≤2 дней, упаковка под габарит.
- **Диваны (WB)** — выигрывают цена и отзывы: коридор 28–42 тыс ₽, рассрочка, отзывы с фото.

Пять гипотез в разных стадиях: новая (ценовой коридор диванов), принятая с рассчитанным тестом (отзывы с фото), идущий тест с набором мощности и предупреждениями о загрязнении (видеообложка кресел), подтверждённый результат, раскатанный тремя волнами на 11 артикулов с контрольной группой из 5 (экспресс-доставка стеллажей, +412 000 ₽/мес), и проваленный тест (обложка с ценой: CTR +22%, заказы −6%), где решение ждёт пользователя. Второй кабинет «Гринвич» пустой — для пустых состояний.

## Что внутри

- **Дашборд** — KPI со спарклайнами, карта категорий с отметками нормы/разрывов, свежие паттерны и события, активные гипотезы и тесты с прогрессом, плитки достижений и провалов с суммами в рублях, компактная лента действий. Каждая плитка ведёт вглубь.
- **Категории** — досье: распределения бенчмарков с позицией селлера и лидеров, структурированные паттерны с долей лидеров и силой признака, таймлайн событий площадок с пометкой влияния, построчное сравнение карточек с нормой. Полный CRUD.
- **Гипотезы** — единый объект со степпером пяти состояний: факт категории, проваленная стадия воронки, ожидание в рублях и приоритет; принятие с расчётом статистической мощности (двухдолевой z-тест); завершение с доверительным интервалом и контрольными метриками; ровно два решения — откат или волны с контрольной группой; линии «управляемые против контроля».
- **Агент без отдельной вкладки** — контекстные бейджи с временем и откатом у каждого изменения, раскрытие «как получено» (источник, выборка, период, метод) у чисел и утверждений, выдвижная панель свежих действий с любого экрана. Откат любого действия — с подтверждением и записью в журнал.
- **Журнал** — фильтры по автору/типу, поиск, CRUD записей, откат.
- Аутентификация (сессии + токен), переключатель кабинетов, постоянное хранилище SQLite, пустые состояния, скелетоны загрузки, оптимистичные обновления, адаптивная вёрстка.

## Стек

- **Фронтенд:** React 18, Vite, TanStack Query (кэш, оптимистичные мутации), React Router. Все графики — рукописный SVG: распределения с позицией селлера, радары профилей, спарклайны, линии с контрольной группой, интервалы эффектов, волны, таймлайн.
- **Бэкенд:** Node 22 + Express, SQLite через встроенный `node:sqlite` (файл `data/lemma.db`, WAL). Пароли — scrypt, сессии в БД, cookie + Bearer.
- **Палитра:** `#2F4F4F` — заголовки, графики, подтверждённые результаты, первичные действия; `#DCDCDC` — границы и нейтральные состояния; белый фон, графитовый текст, приглушённые статусные цвета.

```

```
